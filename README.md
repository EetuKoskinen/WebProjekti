# Projekti
Opettelin web ohjelmointia ja tein noin kahden viikon projektin. Projektissa käytin css, html, javascriptiä ja supabasea tietokantojen luonnissa.
Projekti on simppeli opettaja/opiskelija sivu, missä voi luoda uuden opettajan/opiskelijan. Opettajana voi katsoa oppilaiden profiileja, luoda tehtäviä, tarkistaa palautettuja tehtäviä ja lähettää oppilaalle viestejä. Oppilaana pystyy tehdä tehtäviä ja muokata niitä (Ellei opettaja ole jo tarkistanut).
